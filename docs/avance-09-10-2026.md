# HOSPLab Guardian
## Avances del 09/10/2026

### Instalación y configuración de Windows 11

Hoy he continuado con la configuración del entorno virtual y me he centrado en terminar de preparar el equipo Windows 11, que será uno de los clientes conectados al servidor del hospital.

Una vez instalado Windows 11, he creado una cuenta local para poder acceder al equipo y realizar las primeras configuraciones.

Después he configurado los adaptadores de red de VirtualBox. He dejado uno en NAT para tener conexión externa y otro en la red interna HospLab, que es la que utilizarán las máquinas virtuales para comunicarse entre ellas.

### Configuración de la red

Para que Windows 11 pudiera comunicarse con el servidor, he configurado las siguientes direcciones:

**Servidor Windows Server (SRV-AD01):**
- IP: 10.10.10.10
- Máscara: 255.255.255.0
- DNS: 127.0.0.1

**Cliente Windows 11 (W11-CL01):**
- IP: 10.10.10.20
- Máscara: 255.255.255.0
- DNS: 10.10.10.10

En los adaptadores de la red interna he dejado la puerta de enlace vacía.

### Comprobaciones y unión al dominio

Después de configurar la red, he realizado varias pruebas para comprobar que Windows 11 podía comunicarse con el servidor.

Primero he utilizado el comando ping para verificar la conexión entre ambos equipos.

También he comprobado la resolución DNS con nslookup, ya que al principio Windows 11 estaba consultando otro servidor DNS y no encontraba correctamente el dominio.

Una vez solucionado, he conseguido que Windows 11 reconociera el dominio hosplab.local.

El siguiente paso ha sido cambiar el nombre del equipo a W11-CL01 y unirlo al dominio utilizando las credenciales del administrador.

La unión se ha realizado correctamente y he podido comprobar desde Windows Server que el ordenador aparecía dentro de Active Directory, en el apartado Computers.

Después de reiniciar Windows 11, he iniciado sesión utilizando la cuenta Administrador del dominio.

Para terminar, he ejecutado el comando whoami y he comprobado que el resultado era:

hosplab\administrador

Con esto he confirmado que Windows 11 ya está unido al dominio y que puedo iniciar sesión utilizando una cuenta de Active Directory.

### Problemas que he encontrado

Durante la configuración he tenido algunos problemas con las direcciones IP y los DNS.

Al principio, Windows 11 no conseguía comunicarse correctamente con el servidor porque la configuración de red no coincidía con la que tenía Windows Server.

Después de revisar las direcciones y corregirlas, he conseguido establecer la comunicación.

También he tenido que revisar qué servidor DNS estaba utilizando Windows 11 para que pudiera localizar el dominio.

Finalmente, después de estas comprobaciones, he conseguido completar la unión al dominio.
